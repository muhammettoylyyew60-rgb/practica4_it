## Файлы проекта

- `make_data.py` — генерация исходных данных по номеру варианта.
- `store.py` — чтение и запись данных, проверка результатов.
- `iam.py` — логины, пароли, роли и создание учётных записей.
- `check_passwords.py` — проверка 1000 паролей.
- `role_matrix.csv` — матрица должностей и разрешений.
- `audit.py` — аудит учётных записей и прав.
- `fix.py` — исправление нарушений и запись в журнал.
- `logwatch.py` — анализ журнала входов.

## Порядок запуска

Выполните в PowerShell из папки проекта. При каждом запуске
`make_data.py` введите номер варианта 16.

```powershell
py make_data.py
py check_passwords.py
py iam.py
py make_data.py
py audit.py
py fix.py
py audit.py --after-fix
py logwatch.py
```

Повторный запуск `make_data.py` восстанавливает исходные данные
для проверки аудита. Папка `data/` исключена из Git.
